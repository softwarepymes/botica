# BoticaControl

Sistema de control de botica/farmacia con gestión de inventario, ventas, cierres de caja y alertas de vencimiento. Conectado a Supabase.

## Funcionalidades

- 📦 **Inventario** - CRUD de medicamentos con stock, precios y fecha de vencimiento
- 💰 **Módulo de Ventas** - Carrito de compras, búsqueda por código/nombre/principio activo, múltiples métodos de pago
- 📊 **Dashboard** - Resumen de ventas, ingresos, ganancias, alertas de stock bajo y próximos a vencer
- 🔒 **Cierre de Caja** - Reportes comprimidos con detalle de productos vendidos
- ⏳ **Alertas de Vencimiento** - Productos próximos a vencer (30 días) y vencidos
